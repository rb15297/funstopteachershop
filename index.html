Privacy policy

This app posts pins to one Pinterest business account owned by the person who runs it.

It stores the Pinterest OAuth access token and refresh token only on that person's computer, in their home config folder. It does not send those tokens to any server other than Pinterest's API.

It does not collect visitor data, and it does not post a pin unless that pin is listed in a local queue file with a Teachers Pay Teachers link the account owner added.

To disconnect, delete the token file on the computer and remove the app in the Pinterest developer portal.
